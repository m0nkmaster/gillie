# Roosta roadmap

- **Resizable columns** — Drag a divider or move it with the keyboard and have each page remember its widths.
- **Roosta updates** — Update and restart the Mac app or Python installation from Settings, preserving the workspace.
- **Worker token usage** — Show input and cache tokens per run, then use those figures to find where smaller prompts or models would help.
- **MCP servers per worker** — Let each worker load just the servers/tools it needs.
- **Add a chat to the inbox** — Pin an existing conversation as a card so you can return to the same thread later.
- **Assistant priorities** — Use the cards people act on or ignore to decide when a priority deserves a new card.
- **Mac menu bar** — Open top inbox items, new chats and the Office, see running or unhealthy workers, and snooze notifications.
- **Pulse constellation** — Let the map fill the available space and open project details in a drawer when you select a star.
- **Project file navigation** — Step through neighbouring files from the preview, even when you arrived through search.
- **Skills on the Workers page** — See skills that don't have a schedule.
- **Open workspace** - A link on the Workspace page to open the workspace in the OS's file browser.
- **Windows app** - A windows version of the Roosta app.

## Under consideration

- **Chat controls** — Inspect tool calls, stop a reply, or edit an earlier message and retry from there.
- **Workspace collections** — Decide which collections come out of the box beyond All knowledge, Projects and Topics, using only what a standard workspace holds.
